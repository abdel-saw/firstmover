# Demo script — target 2 minutes 35 seconds

Record after actual model and PayPal sandbox verification. Show the deployed build and distinguish fixtures from sandbox operations. Use your own narration, original screen footage, no copyrighted music, and no third-party logos beyond any permitted integration UI. Keep the public video under three minutes.

| Time | Screen | Narration |
| --- | --- | --- |
| 0:00–0:15 | Case inbox | “A customer says they cancelled, but another renewal appeared. The merchant's evidence is scattered. CaseWeave brings it into one reviewable case.” |
| 0:15–0:40 | Sample timeline and source | “This labelled sample shows the request, cancellation record, payment, and agreement. Every event links to its source. A request alone does not establish completed cancellation.” |
| 0:40–1:05 | Actual model analysis | “The checks compare the recorded timestamps. Our configured model prepares a source-linked draft. Coverage measures available record types, not the probability of winning.” |
| 1:05–1:30 | Missing-evidence case, add a record | “Here, confirmation is missing. We can add a source record and rerun the checks. New evidence invalidates the old draft and approval.” |
| 1:30–1:55 | Review modal | “The merchant edits and approves the exact response. Source references and gaps remain visible. CaseWeave prepares evidence; it does not adjudicate.” |
| 1:55–2:20 | Real sandbox import and submission | “This separate case was retrieved from PayPal sandbox. We refresh the case status and permitted actions, then send the approved note. The audit records API acceptance, not a case outcome.” |
| 2:20–2:35 | Audit, export, repository link | “Our goal is more complete evidence with less repeated investigation. Judges can try isolated sample cases at the hosted URL, and all code and setup instructions are public.” |

If a sandbox case is not eligible for submission, show the real retrieval and the blocked action honestly. Describe that limit in the submission. Do not label a simulated receipt as an actual API response. Show the actual model name/provider used; leave operator tokens and credentials out of the recording.
