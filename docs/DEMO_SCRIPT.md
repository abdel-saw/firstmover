# FirstMover screen recording script

**Target length 2:45**. Timecodes refer to the finished video. Resume recording a few seconds before each result or deadline so viewers see what changes. Record narration in English.

## Before recording

- Sign into the merchant workspace and verify its PayPal connection, the $0.01 Payouts check, and one live AI draft with the current Render service. Run through both sandbox settlement outcomes once before recording.
- Open three separate browser profiles or sessions. Keep the merchant dashboard in one and sign into two distinct personal sandbox buyer accounts in the others. Make the demo windows large enough to read the ledger.
- Set up a second sandbox campaign, **Saturday printmaking group**, with two authorized buyers and a comfortable deadline. Leave it ready to settle during the recording. On camera, explain that both commitments were approved before recording.
- For the main campaign use **Sunday printmaking group**, **2 people**, **$10 each**, **1 early place**, and a **$1 bonus**. Select a **5-minute window** for the recording. Use one buyer. Resume before the real deadline expires, then settle.
- Keep credentials, account emails, bookmarks, notifications and sensitive provider identifiers outside the capture. Use your own voice and visuals. Crop or mask third-party logos and branded overlays unless you have permission. For checkout, you can record the FirstMover button and verified return while keeping the third-party sign-in popup outside the capture.
